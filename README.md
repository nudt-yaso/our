# 拾玖 · 时光 · 纸册版

> 一个装在文件夹里的恋爱纪念册。
> 起点：**10 月 19 日 23:45** —— 从这一刻起，你们的时间有了名字。

双击 `index.html` 就能用，不需要联网、不需要安装、不需要服务器。
所有记录只保存在你自己的浏览器里，不会上传到任何地方。

---

## 一、怎么打开

| 设备 | 做法 |
|---|---|
| **电脑**（推荐） | 双击 `index.html`，用 Chrome / Edge 打开 |
| **手机 · 同一个 WiFi** | 电脑上进入这个文件夹，执行 `python -m http.server 8123 --bind 0.0.0.0`，然后在手机浏览器打开 `http://电脑IP:8123`（电脑 IP 用 `ipconfig` 看，形如 192.168.1.23）。用手机浏览器菜单里的「添加到主屏幕」，就和 App 一样了 |
| **手机 · 长期 / 异地** | 部署到静态托管拿一个 https 网址（**国内推荐 GitHub Pages 或 Gitee Pages**，下面有步骤）。Netlify / Vercel 在国内经常打不开，别先试它们 |
| **只是把文件传到手机**（不推荐） | 能打开，但**多数手机浏览器不允许 `file://` 页面写入本地存储**，记录存不住，等于只能看不能写 |

> **关于数据**：记录存在浏览器里，并且是**按网址分开存**的（`http://192.168.1.23:8123` 和 `https://xxx.pages.dev` 是两个仓库）。
> 所以换网址、清缓存、换浏览器 = 看不到旧记录。**换之前先去设置里「导出同步包」**，到新网址再「合并同步包」。
> 另外手机和电脑不是同一个浏览器，天然也不会共享记录 —— 想两边都有，用「导出 / 合并」或云端同步。

### 装到主屏幕（就是「安装包」的效果）

这个应用带了 `manifest.webmanifest` 和离线缓存（`sw.js`），所以**用网址打开之后**可以装成一个真正的 App：
有自己的图标（朱砂印章）、全屏、断网也能翻。

- **Android（Chrome / Edge / 夸克）**：浏览器菜单 → 「添加到主屏幕」/「安装应用」
- **iPhone（Safari）**：底部「分享」按钮 → 「添加到主屏幕」
- 装好以后图标是红底「拾」，点开没有地址栏，和下载的 App 一样
- 桌面版 Chrome 右上角地址栏也会出现一个小图标，可以「安装拾玖 · 时光」

> 这一步不需要任何安装包、不用签名、不用上架应用商店，而且以后改了这个文件夹里的东西，手机端**自动就是新的**。
>
> **如果你确实想要一个 `.apk` 文件**：先拿到 https 网址，再去 <https://www.pwabuilder.com/>，
> 粘贴网址，它会生成带签名的 APK（Android 用）。
> 但它有个代价：以后每次改版都得重新打包、重新发给对方安装，所以自己用的话，主屏幕图标更合适。

### 部署到网上（Netlify / Vercel 打不开就走这两条）

这两个平台在国内经常连不上，不是你的问题。优先用下面两个，都**只要浏览器、不用装 git**。

**路线 A · GitHub Pages（免费、不用备案）**

1. 打开 <https://github.com> 注册 / 登录
2. 右上角 + → New repository，名字填 `shijiu`，选 **Public**，Create
3. 进仓库 → **Add file → Upload files** → 把下面这些文件**全部**拖进去 → Commit changes
   `index.html` `styles.css` `app.js` `data.js` `manifest.webmanifest` `sw.js`
   `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png`
4. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → 分支 `main`、目录 `/ (root)` → Save
5. 等 1 分钟，网址是 `https://你的用户名.github.io/shijiu/`
6. 手机打开这个网址 → 添加到主屏幕 / 安装应用

> 仓库是公开的，但里面只有代码和文案，**没有任何你的记录**（记录在各自浏览器里）。
> 千万**不要**把 App 里生成的「邀请串」或令牌写进任何文件再上传。

**路线 B · Gitee Pages（国内最快，但要实名）**

1. 打开 <https://gitee.com> 注册 → 实名认证（必须，否则 Pages 用不了）
2. 新建仓库（公开）→ 上传同样的文件
3. 仓库 → **服务 → Gitee Pages** → 启动
4. 网址是 `https://你的用户名.gitee.io/shijiu/`

> Gitee Pages 对个人免费版有时会限制开通（提示升级 / 未开放）。遇到就走路线 A。

**路线 C · 不想部署，只用局域网**

电脑上执行 `python -m http.server 8123 --bind 0.0.0.0`，手机连同一个 WiFi 打开 `http://电脑IP:8123`
→ 能正常记录、也能「添加到主屏幕」，但**没有离线**，而且**电脑得开着、必须在同一 WiFi**。
适合先试试手，不适合日常和异地。

## 二、这一册长什么样

整册是一张**纸**。三样东西撑起了它的性格：

- **纸**：米白底色、四周压暗、一层极细的纸纤维颗粒；卡片是信笺，有一圈内框线（双线）。
- **印**：朱砂红是唯一的强调色 —— 标题点、勾选、进度、印章都用它。左上角是「拾玖」方印，
  打过卡以后，首页会自己钤一枚「今日已记」。
- **光**：夜的版本里，纸变成墨色，背后有星。

字体也是分层的：标题用宋体（印刷感），情话、信件、输入框用楷体（手写感），
时钟与编用等宽字（像老式打字机）。

### 四套配色

设置 → 主题：

| 主题 | 是什么 |
|---|---|
| **随时刻**（默认） | 白天是宣纸，19:00 之后自动翻到墨夜，05:00 回到宣纸 |
| **宣纸** | 米白纸 + 墨 + 朱砂 |
| **墨夜** | 墨黑纸 + 米白字 + 灯下的朱砂，星星偶尔划过 |
| **胭脂** | 淡粉纸 + 胭脂红，稍微甜一点 |

主题只影响观感，不影响任何数据。

## 三、五个页面

**① 心跳** —— 首页
- 我们在一起的第 **N** 天，秒针实时跳动，浏览器标签页标题也跟着变成「第 N 天」
- 起点那天的具体日期**不显示在页面上**（只在「设置 → 我们确认关系的时间」里，属于内部记录）
- 下一个纪念日的表盘（刻度圈 + 进度环）
- 今日情话（每天自动换一句，也能手动「换一句」）
- 「记一笔心动」把此刻存进恋爱银行
- 「今日打卡」记录当天心情，累计连续天数；打过卡首页会盖章
- 最近三条心动速览

**② 纪念日**
- 距离下一个里程碑还有几天，进度条
- 23 个里程碑做成一份年表：100 天 / 520 天 / 999 天 / 1314 天 / 一周年 ……
  天数型按「第 N 天」算，**周年型永远落在同一个 10 月 19 日**，不会算错
- 自定义纪念日做成小纸条（生日、第一次见面、第一次牵手……），支持每年 / 每月 / 仅一次

**③ 拾光集**
- 线装书式的时间轴，可按「心动 / 回忆」筛选
- 每条都能带一张照片（自动压缩到 1000px，显示成有白边的相纸；点一下可以看大图）
- 自动标注「在一起第 N 天」

**④ 胶囊**
- **时间胶囊**：写一封信定个解锁日，封上火漆；到期之前连你自己都读不到，到期才会出现「拆开这封信」
- **每日一问**：每天一个问题，答完存进历史；写答案的地方是横线信纸

**⑤ 小事**
- 一百件情侣小事清单，逐件打勾，进度条（顶部显示「已完成 / 总共」）
- **清单可以自己改**：每行右边的小铅笔 → 改文字、改分类、或者删掉；
  列表最下面「＋ 添一件」→ 加一件只有你们懂的（分类也可以自己起）
- 第一次打开会把内置的 100 件搬进你的数据里，之后所有修改都存在本地、也会跟着云端同步
- 「随机抽一件」—— 今天不知道干什么就让它抽

## 六、异地恋怎么「同步」

这个 App 没有服务器，数据存在**各自设备的浏览器**里（键名 `shijiu.love.v1`）。
所以不存在「自动同步」，但有一半东西是**天生同步**的：

- 在一起第几天、纪念日倒计时、每天的情话与每日一问 —— 只要两边填的起始时间一样，算出来完全一致
- 100 件小事、里程碑 —— 同一份清单

需要互传的只有四样：**心动记录、回忆、时间胶囊、清单打勾**。

### 三条路，按麻烦程度排

| 方案 | 难度 | 代价 |
|---|---|---|
| **① 手动互传**（导出 / 合并） | 零门槛，不需要账号 | 每天要手动传一次文件 |
| **② GitHub 私有 Gist** | 一次配置约 5 分钟，之后点一下「立即同步」 | 要注册 GitHub、生成一个令牌 |
| **③ Gitee 码云** | 同上，国内更快 | App 里已内置，但我没实测过，报错就把日志发我 |

### 手动互传（最省事）

**设置 → 导出同步包** → 微信发给她 → 她 **设置 → 合并同步包** → 选那个文件。

- 合并是**只增不删**的：按 ID 去重，她答过的每日一问不会被你覆盖
- 来回传多少次都不会出问题
- 想完全恢复一个旧备份：先「清空全部」，再「合并同步包」

### 云端同步（配一次就不用再传文件）

设置 → 云端同步，服务商选 **GitHub 私有 Gist**（或 **Gitee**），填访问令牌
（GitHub：Settings → Developer settings → Personal access tokens → 勾选 `gist`），
点「创建同步空间」得到同步码，再「复制邀请串」（`SJ1.xxxx`）发给她，
她那边点「用邀请串加入」，之后任何一边点「立即同步」即可。

**打开「自动同步」之后就不用点了**（同一个面板里，一个开关）：

- 打开 App 时对齐一次
- 从后台切回前台时对齐一次（30 秒内不重复）
- 写完一条（心动 / 回忆 / 打卡 / 打勾 / 信）**8 秒后自动推上去**
- 同步是**合并**语义，两个人同时写不会互相覆盖；有新东西才会弹一句「已同步 · 新增 N 条」
- 失败是静默的（不打扰你），下次触发时自动重试；网络不好时建议临时关掉

- 邀请串里包含令牌，**只发给她一个人**
- 同步全程只调用 `api.github.com`，**不打开网页，也不需要翻墙**
- 记录里照片太多（超过约 900KB）时，本次会自动只同步文字并提示
- Gitee 的接口按同样协议写了，但没有实测过

### 为什么不用坚果云 / OneDrive / WebDAV

静态网页只能通过浏览器的 `fetch` 访问网络，而网盘的 WebDAV 接口**不允许跨域**（没有 CORS 头），
浏览器会直接拦掉。所以能选的只有「允许跨域」的服务：GitHub / Gitee 的 API、自建的服务端。
真要用网盘，只能退回到 ① 手动导出。

> 如果 GitHub 实在不想弄，跟我说一声，我可以再加一个**免注册的同步后端**
> （拿一串随机 ID 就能读写的那种，不用账号）——代价是安全性靠「ID 不外传」，不如私有 Gist。

## 八、想自己改内容

`data.js` 里全是纯文本，用记事本就能改，改完刷新页面生效：

- `QUOTES` —— 情话，建议换成你们自己的话
- `BUCKET` —— **初始**的一百件小事（只在第一次打开时导入，之后在 App 里改就行）
- `QUESTIONS` —— 每日一问
- `MILESTONES` —— 里程碑

`styles.css` 开头是四套配色的变量（`--paper` / `--ink` / `--vermilion` / `--gold`），
改颜色只改那几行就够了。

## 九、文件说明

```
index.html            页面结构（含 PWA 的图标与 manifest 声明）
styles.css            外观（纸 / 印 / 光）
data.js               文案内容（可自由修改）
app.js                全部功能逻辑

sw.js                 离线缓存（改了上面几个文件后，把里面的 CACHE 版本号 +1）
icon-192 / icon-512 / icon-maskable-512 / apple-touch-icon .png
                      主屏幕图标（朱砂印章）
README.md             这份说明
```

没有依赖、没有构建、没有网络请求（云端同步时才会访问 API）。
想发给别人，整个文件夹压缩一下就行。
